Şekil 2: Veritabanı Şeması (ERD)

Entity Relationship Diagram — SQLite 3  ·  Kaynak: backend/backend/src/db.js

👤 users
🔑 id INTEGER PK AUTO
name TEXT
email TEXT UNIQUE @pau.edu.tr zorunlu
password_hash TEXT bcrypt 10-round
role TEXT admin / staff
employee_no TEXT
department TEXT
approval_status TEXT pending / approved / rejected
📍 locations
🔑 id INTEGER PK AUTO
name TEXT
description TEXT
🚪 rooms
🔑 id INTEGER PK AUTO
🔗 location_id INTEGER FK → locations.id
name TEXT
description TEXT
latitude REAL
longitude REAL
🧹 cleaning_logs
🔑 id INTEGER PK AUTO
🔗 user_id INTEGER FK → users.id
🔗 room_id INTEGER FK → rooms.id
cleaned_at TEXT DEFAULT datetime('now')
status TEXT
notes TEXT
image TEXT base64 encoded
📅 scheduled_tasks
🔑 id INTEGER PK AUTO
🔗 room_id INTEGER FK NOT NULL → rooms.id
title TEXT NOT NULL
description TEXT
scheduled_for TEXT NOT NULL
🔗 assigned_user_id INTEGER FK → users.id
status TEXT DEFAULT 'pending'
🔗 completed_log_id INTEGER FK → cleaning_logs.id
created_at TEXT DEFAULT datetime('now')
📦 inventory
🔑 id INTEGER PK AUTO
name TEXT NOT NULL
unit TEXT NOT NULL litre, adet, kg …
current_amount REAL NOT NULL DEFAULT 0
min_threshold REAL NOT NULL DEFAULT 0
unit_cost REAL DEFAULT 0 (ABC maliyet)
category TEXT
created_at TEXT DEFAULT datetime('now')
updated_at TEXT DEFAULT datetime('now')
📋 inventory_logs
🔑 id INTEGER PK AUTO
🔗 inventory_id INTEGER FK NOT NULL → inventory.id (CASCADE)
🔗 user_id INTEGER FK → users.id
action TEXT NOT NULL in / out / adjust
amount REAL NOT NULL
note TEXT
created_at TEXT DEFAULT datetime('now')
🎯 kpi_targets
🔑 id INTEGER PK AUTO
🔗 user_id INTEGER FK NOT NULL UNIQUE → users.id
target_value INTEGER NOT NULL DEFAULT 15
🔗 set_by INTEGER FK NOT NULL → users.id (admin)
set_at TEXT DEFAULT datetime('now')

🔗 İlişkiler (Relationships)

locations (1) ────< (N) rooms — Bir konumda birden fazla oda bulunabilir
users (1) ────< (N) cleaning_logs — Bir personel birçok temizlik kaydı oluşturabilir
rooms (1) ────< (N) cleaning_logs — Bir oda birçok kez temizlenebilir
rooms (1) ────< (N) scheduled_tasks — Bir odaya birden fazla görev planlanabilir
users (1) ────< (N) scheduled_tasks — Bir kullanıcıya birden fazla görev atanabilir
cleaning_logs (1) ────o (1) scheduled_tasks — Görev tamamlandığında ilgili log ile eşleştirilir
inventory (1) ────< (N) inventory_logs — Malzemenin tüm giriş/çıkış hareketleri (CASCADE DELETE)
users (1) ────< (N) inventory_logs — Stok hareketi yapan kullanıcı kaydı
users (1) ────o (1) kpi_targets — Her kullanıcı için en fazla bir KPI hedefi (UNIQUE)
users (admin, 1) ────< (N) kpi_targets — Hedefi belirleyen admin (set_by FK)

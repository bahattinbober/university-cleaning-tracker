📌 Mimari Notları:
• Stateless backend — JWT ile kimlik doğrulama, sunucu tarafı oturum yok
• REST API standartları — HTTP fiilleri (GET/POST/PUT/DELETE), JSON payload
• Role-based access control — admin ve personel rolleri, ayrı yetki seviyeleri
• Rate limiting — aşırı istek koruması (express-rate-limit)
• Şifreler bcrypt ile hash'lenir (10 round salt)
• CORS whitelist — yalnızca ALLOWED_ORIGINS'teki kaynaklara izin verilir
• Fail-fast başlatma — JWT_SECRET eksikse process.exit(1) çağrılır
